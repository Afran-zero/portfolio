## Reading order for a new agent

If you are an agent picking up this repo cold, read in this order:

1. **`README.md`** *(not yet written — see STATUS.md)* — what the repo is, how to run it.
2. **`PLAN.md`** — the full design + architecture plan. Sections 1–74.
3. **`progress/INDEX.md`** (this file) — file map.
4. **`progress/STATUS.md`** — what is built vs. in progress vs. planned.
5. **`progress/DECISIONS.md`** — the *why* behind non-trivial calls.
7. **`progress/GLOSSARY.md`** — domain terms.
8. **The relevant skill** in `skills/` — load only the skill for the area you're touching.

Then start working.

## How to keep this map accurate

When you:

- **Create a file** → add a row to the appropriate table above.
- **Delete a file** → remove the row.
- **Change a file's purpose** → edit the row.
- **Create a folder** → add a section.
- **Move or rename** → update both old (mark deleted) and new paths.

Keep rows to **one line**. If a file's purpose needs more, link to a dedicated doc inside the folder, not a paragraph here.
